How this simulation works

Each station processes one item at a time. Three workers is the baseline staffing level; changing staffing proportionally changes all station capacities. Downtime is modeled as a reduction in effective processing rate, not as random failures. Finished items wait if the next buffer is full. The bottleneck shown is the station with the lowest effective capacity, though startup and blocking also affect actual throughput.

One real second represents one simulated minute. Throughput is calculated from completions in the most recent simulated hour (or elapsed simulated time if less than one hour). This is an instructional model, not a validated industrial forecast.
